# Исходные данные КРМ

| Файл | Назначение | Правило использования |
|---|---|---|
| [krm-v3.0.xlsx](krm-v3.0.xlsx) | исходная книга КРМ версии 3.0 из шаблона репозитория | не редактировать; переносить исходный код и формулировку, а предметный дескриптор добавлять отдельно |

Использованные в дисциплине целевые компетенции: `LC-1`, `BD-1`, `ML-2`. Целевая роль — Data Analyst. Проверка формулировок выполнена по листам `Роли-компетенции наглядно`, `Роли - определения и функции` и `Профессиональные`.

Контрольная сумма файла SHA-256: `749d9161b3fde84effb8a73f30a5c645669fcec99fc4d5b146eaf8c98478eb89`.

Для итоговой сверки использованы:

- лист `Роли-компетенции наглядно`: `C9 = BD-1`, `K9 = П` для роли Data Analyst;
- лист `Профессиональные`: определения `LC-1`, `BD-1`, `ML-2` и формулировки индикаторов `LC-1.1`, `BD-1.2`, `BD-1.3`, `BD-1.5`, `ML-2.1`–`ML-2.3`.

Репозиторий хранит исходные формулировки отдельно от предметных дескрипторов. Поэтому уровень П в ролевой матрице не переносится автоматически в одну дисциплину: «Прикладной анализ данных» обоснованно фиксирует уровень С, а дальнейший маршрут описан в [траектории роли](../docs/role-trajectory.md).

Учебные датасеты не дублируются в этой папке. Их источники, лицензии и риски приведены в [каталоге ресурсов](../resources/datasets/README.md).
