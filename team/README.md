# Команда проекта

## Рабочая карточка

| Участник | Организация | Роль | Зона ответственности | Профиль |
|---|---|---|---|---|
| `DiDiLight` | учебная рабочая группа курса по разработке РПД | владелец и координатор репозитория | концепция курса, сведение РПД и ФОС, публикация комплекта | [GitHub](https://github.com/DiDiLight) |

В истории Git используется технический профиль. Репозиторий не позволяет достоверно восстановить официальные ФИО, должность и организацию, поэтому эти сведения не подменены догадками. Их добавляют после согласия автора и решения организации.

## Роли при развитии комплекта

- координатор и ответственный за РПД;
- эксперт по КРМ;
- разработчик КИМ по данным;
- разработчик КИМ по моделированию;
- методист по оцениванию;
- технический редактор и ответственный за воспроизводимость.

## Фиксация вклада

Для каждого участника указываются концепция, методология, разработка КИМ, программная реализация, проверка, редактирование и управление проектом. История коммитов и Pull Request используется как дополнительное подтверждение вклада.
