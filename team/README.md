# Команда проекта

## Рабочая карточка

| Участник | Организация | Роль | Зона ответственности | Профиль |
|---|---|---|---|---|
| Рабочая группа дисциплины | образовательная организация-разработчик | авторский коллектив | концепция, РПД, КИМ, рубрики, ресурсы и проверка качества | персональные GitHub-профили добавляются участниками перед публичной защитой |

Перед публичной публикацией координатор заменяет коллективную строку фактическим списком авторов и подтверждает согласие на указание контактов.

## Рекомендуемые роли

- координатор и ответственный за РПД;
- эксперт по КРМ;
- разработчик КИМ по данным;
- разработчик КИМ по моделированию;
- методист по оцениванию;
- технический редактор и ответственный за воспроизводимость.

## Фиксация вклада

Для каждого участника указываются концепция, методология, разработка КИМ, программная реализация, проверка, редактирование и управление проектом. История коммитов и Pull Request используется как дополнительное подтверждение вклада.
