# КИМ-0. Входная диагностика

## Назначение

Проверить, готов ли студент работать с математическими обозначениями, статистическими выводами, Python и табличными данными. Результат нужен для планирования повторения и не входит в итоговые 100 баллов.

## Статус в дисциплине

КИМ-0 проводится на первой неделе до оцениваемых контрольных точек. Это полноценное диагностическое средство с едиными условиями, заданиями, ориентирами и правилами обратной связи, но не способ накопления баллов. Его результат нельзя прибавлять к КИМ-1–КИМ-6 или использовать для снижения итоговой оценки.

## Проверяем

`ВК-1.1`, `ВК-1.2`, `ВК-2.1`, `ВК-2.2`, `ВК-3.1`, `ВК-3.2`, `ВК-4.1`, `ВК-4.2` на базовом уровне.

## Материалы

Преподаватель готовит:

- `orders.csv` со столбцами `client_id`, `order_date`, `category`, `amount`, `region`;
- `clients.csv` со столбцами `client_id`, `registration_date`;
- диагностический ноутбук с одной ошибкой импорта и незаданным случайным состоянием;
- пустой файл ответа, в котором восемь разделов соответствуют восьми индикаторам.

## Задание

### 1. Функция и минимум — `ВК-1.1`

Для функции \(L(w)=(w-3)^2\) найдите производную, точку минимума и своими словами объясните, что означает минимум функции потерь при настройке модели.

### 2. Векторы и расстояние — `ВК-1.2`

Даны два объекта \(x=(1,2)\) и \(y=(4,6)\). Найдите евклидово расстояние между ними и объясните, как изменится расстояние, если второй признак измерять в тысячах, а не в единицах.

### 3. Описательная статистика — `ВК-2.1`

Для набора `2, 3, 3, 4, 18` найдите среднее, медиану и межквартильный размах. Укажите, какая характеристика лучше описывает типичное значение и почему.

### 4. Статистическая интерпретация — `ВК-2.2`

В исследовании получена корреляция 0,65 между временем в приложении и суммой покупки. Объясните:

1. что можно утверждать по этому результату;
2. чего утверждать нельзя;
3. какая дополнительная информация нужна до практического вывода.

### 5. Функция Python — `ВК-3.1`

Напишите функцию, которая принимает список сумм заказов и возвращает долю значений выше заданного порога. Обработайте пустой список и покажите два тестовых вызова.

### 6. Повторяемый запуск — `ВК-3.2`

Откройте диагностический ноутбук, исправьте ячейку с ошибкой импорта, задайте фиксированное случайное состояние и выполните ноутбук сверху вниз. В последней ячейке кратко запишите, что мешало повторному запуску.

### 7. Обработка таблиц — `ВК-4.1`

С помощью pandas:

1. прочитайте оба файла;
2. проверьте типы и пропуски;
3. объедините таблицы по `client_id`;
4. посчитайте число заказов и медианную сумму по регионам;
5. назовите возможную причину потери строк при объединении.

### 8. SQL и происхождение результата — `ВК-4.2`

Запишите SQL-запрос, который выводит регионы с числом заказов и общей суммой, оставляя только регионы с десятью и более заказами. После запроса одной фразой укажите, из каких таблиц и преобразований получен результат.

## Формат сдачи

Студент сдаёт:

1. файл с ответами на задания 1–4 и SQL-запросом;
2. выполненный диагностический ноутбук;
3. короткий `README` с командами запуска;
4. ссылку на commit или один архив, если учебная система не использует Git.

Преподаватель хранит диагностический лист с уровнем по каждому индикатору и назначенным повторением. В итоговую ведомость этот лист не переносится.

## Оценивание

Каждое задание получает диагностический уровень. Обозначения 0–2 не являются баллами дисциплины и не суммируются с проектом.

| Уровень | Признак результата |
|---:|---|
| 0 | действие не выполнено или результат нельзя интерпретировать |
| 1 | типовое действие выполнено, основная интерпретация верна |
| 2 | результат верен, объяснение учитывает ограничение или возможную ошибку |

Входное умение подтверждено при уровне не ниже 1. Сумма восьми уровней может использоваться только как обзор для преподавателя: сильный результат по одному индикатору не компенсирует уровень 0 по другому.

## Ориентиры для проверки

| Индикатор | Ожидаемое действие | Признак уровня 1 | Типичный пробел |
|---|---|---|---|
| `ВК-1.1` | найти производную и связать минимум с настройкой модели | \(L'(w)=2(w-3)\), минимум при \(w=3\); дано содержательное объяснение | найдено число без объяснения смысла функции потерь |
| `ВК-1.2` | вычислить расстояние и заметить влияние масштаба | расстояние равно 5; изменение единиц меняет вклад признака | расстояние рассчитано, но проблема масштаба не замечена |
| `ВК-2.1` | выбрать устойчивое описание ряда с выбросом | среднее 6, медиана 3, Q1 = 3, Q3 = 4, IQR = 1; медиана лучше описывает типичное значение | среднее выбирается автоматически без анализа выброса |
| `ВК-2.2` | ограничить интерпретацию корреляции | названа связь, но не причинность; запрошены контекст, дизайн и возможные смешивающие факторы | корреляция объявлена доказанной причиной |
| `ВК-3.1` | написать небольшую проверяемую функцию | функция обрабатывает пустой список и показаны два содержательных теста | код работает только на одном непустом примере |
| `ВК-3.2` | обеспечить повторный запуск | исправлена зависимость, задано случайное состояние, ноутбук проходит сверху вниз | результат зависит от скрытого состояния ячеек |
| `ВК-4.1` | прочитать, проверить, объединить и агрегировать таблицы | показаны типы, пропуски, результат объединения и контроль числа строк | объединение выполнено без проверки потерь и гранулярности |
| `ВК-4.2` | составить агрегирующий запрос и описать происхождение | корректно использованы группировка и `HAVING`, назван путь данных | условие на агрегат помещено в `WHERE` или происхождение не указано |

## Проведение

- 60 минут;
- индивидуальная работа;
- первые четыре задания выполняются без программирования;
- последние четыре — в подготовленном ноутбуке или локальной среде;
- ответы и код сдаются одним комплектом.

## Обратная связь и повторная проверка

- при уровне 0 преподаватель назначает материал из [карты выравнивания](remediation-map.md);
- один или два нулевых результата закрываются адресным заданием;
- при трёх и более составляется план повторения на первые две недели;
- повторная проверка длится 10–15 минут и включает только недостигнутые индикаторы;
- работа над КИМ-1 может начаться параллельно, если пробел не мешает постановке проекта.

## Внешние ресурсы и генеративный ИИ

Разрешена стандартная документация Python, pandas и SQL. Готовые решения, помощь другого человека и генеративные сервисы не используются: преподавателю нужен исходный профиль, а не максимально полный ответ. Ограничение действует только на диагностическую сессию.

## Самопроверка

- каждый из восьми ответов помечен кодом индикатора;
- вычисления сопровождаются интерпретацией;
- ноутбук выполняется сверху вниз;
- указана команда запуска;
- SQL-запрос содержит объяснение происхождения результата.
