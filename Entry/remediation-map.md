# Карта выравнивания входных знаний

Карта помогает назначить короткое повторение по результатам КИМ-0. Конкретные ссылки преподаватель подбирает из доступной в институте электронной библиотеки или открытых курсов.

| Индикатор | Что повторить | Контроль после повторения |
|---|---|---|
| `ВК-1.1` | функция одной переменной, производная, экстремум, градиент, смысл функции потерь | объяснить минимум простой квадратичной функции и направление градиента |
| `ВК-1.2` | векторы, матрицы, скалярное произведение, нормы, расстояния, масштаб признаков | вычислить расстояние и объяснить влияние разных единиц измерения |
| `ВК-2.1` | выборка, среднее, медиана, дисперсия, квантили, выбросы | выбрать устойчивую характеристику для набора с выбросом |
| `ВК-2.2` | вероятность, корреляция, доверительный интервал, проверка гипотез, причинность | интерпретировать готовый статистический результат и назвать ограничения |
| `ВК-3.1` | функции Python, коллекции, ветвления, циклы, исключения, чтение файлов | написать и проверить небольшую функцию обработки списка |
| `ВК-3.2` | Jupyter, виртуальное окружение, зависимости, порядок выполнения ячеек, random state | выполнить учебный ноутбук с начала без ручных исправлений |
| `ВК-4.1` | типы данных, пропуски, фильтрация, объединение, группировка, гранулярность | собрать сводную таблицу из двух файлов и проверить число строк |
| `ВК-4.2` | `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, `HAVING`, описание происхождения данных | написать запрос с объединением и агрегацией |

Повторная проверка занимает 10–15 минут и включает одно аналогичное задание по каждому недостигнутому индикатору.
