# Входная диагностика

Диагностика проводится на первой неделе и показывает, какие базовые темы студенту нужно повторить до начала моделирования. Она оформлена как полноценный [КИМ-0](kim-00-diagnostic.md), но не влияет на итоговую оценку и не является формальным допуском к дисциплине.

## Что проверяется

Проверяются восемь индикаторов входных компетенций `ВК-1`–`ВК-4`, описанных в [модели компетенций](../docs/competency-model.md#2-входные-компетенции):

- математический аппарат;
- основы вероятности и статистики;
- Python и воспроизводимый запуск кода;
- базовые операции обработки и выборки данных.

## Как провести

- продолжительность — 60 минут;
- работа индивидуальная;
- первые четыре задания выполняются без программирования;
- последние четыре — в подготовленном ноутбуке или локальной среде;
- разрешена стандартная документация Python и pandas;
- ответы и код сдаются одним архивом или ссылкой на репозиторий.

КИМ-0 содержит материалы, восемь заданий, формат сдачи, ориентиры проверки, правила обратной связи и повторной диагностики.

## Как трактовать результат

Каждый индикатор получает диагностический уровень 0–2. Это не баллы дисциплины.

| Результат по индикатору | Решение преподавателя |
|---:|---|
| 2 | входное умение проявляется уверенно |
| 1 | базовый уровень достигнут, достаточно обычной работы по курсу |
| 0 | назначается материал для повторения и короткая повторная проверка |

Сводная сумма уровней используется только как ориентир. Нельзя компенсировать отсутствие навыка Python сильным результатом по математике или наоборот.

## Действия после диагностики

- один или два нулевых результата — студент получает адресное задание на повторение;
- три и более — преподаватель согласует индивидуальный план на первые две недели;
- повторная проверка проводится только по недостигнутым индикаторам;
- рекомендуемые темы собраны в [карте выравнивания](remediation-map.md).
