# Другие материалы

Вспомогательные редактируемые документы размещены в [`docs/attachments`](../docs/attachments/):

- входной профиль обучающегося;
- проект РПД в формате DOCX;
- презентация проекта дисциплины.

Основной проверяемой версией содержания являются Markdown-файлы репозитория. Бинарные документы используются для согласования и могут обновляться после изменения Markdown-версии.
