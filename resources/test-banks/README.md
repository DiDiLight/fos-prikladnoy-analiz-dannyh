# Банки тестовых заданий

Закрытый тестовый банк в обязательной части дисциплины не используется: целевые индикаторы проверяются практическими артефактами и индивидуальной защитой.

Для входной диагностики преподаватель поддерживает отдельный непубликуемый набор коротких задач по Python, статистике, матрицам, качеству данных и SQL. Диагностика не влияет на итоговый балл и не является КИМ целевых компетенций.

Вопросы для защиты формируются из типовых действий, перечисленных в [описании зачёта](../../Exam/README.md), и параметризуются по проекту конкретного студента.
