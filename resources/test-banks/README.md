# Формирующие вопросы и тестовые ситуации

Раздел добавляет разнообразие способов обратной связи, но не создаёт параллельную экзаменационную систему. Основными оценочными средствами остаются КИМ-1–КИМ-6 и индивидуальная защита, а основным свидетельством — выполненный проектный артефакт.

| Материал | Назначение | Статус в оценивании |
|---|---|---|
| [КИМ-0](../../Entry/kim-00-diagnostic.md) | входная диагностика математики, статистики, Python и работы с данными | диагностические уровни; в 100 баллов не входит |
| [мини-коллоквиум](mini-colloquium.md) | проверка валидации, утечек, pipeline и выбора метрик до КИМ-5 | допуск к принятию зависимого этапа и обратная связь; баллов не добавляет |
| [банк вопросов](question-bank.md) | 14 вопросов и практических ситуаций с индикаторами, действиями, ориентирами и типичными ошибками | источник вариантов для формирующей проверки |

В банке нет вопросов на простое запоминание синтаксиса Python. Студент должен выбрать действие, обосновать его и назвать риск неверного решения.

Вопросы для итоговой защиты по-прежнему параметризуются по проекту конкретного студента и берутся из [описания зачёта](../../Exam/README.md), а не подменяются стандартизированным тестом.
