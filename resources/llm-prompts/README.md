# Генеративный ИИ и журнал использования

Генеративный ИИ является вспомогательным ресурсом, а не обязательной технологией дисциплины. Правила конкретного задания имеют приоритет.

## Разрешённые сценарии

- объяснение API и сообщения об ошибке;
- обсуждение альтернативных методов;
- рефакторинг собственного кода;
- языковая редактура;
- генерация тестовых случаев без передачи закрытых данных.

## Журнал

Студент ведёт `ai-usage.md` со следующими полями для каждого существенного обращения:

| Поле | Содержание |
|---|---|
| Дата и сервис | когда и какой сервис использован |
| Цель | какую локальную задачу решали |
| Запрос | полный текст или содержательное резюме |
| Полученный результат | что было предложено |
| Проверка | как ответ проверен по данным, документации или тесту |
| Использование | что вошло в итоговую работу |

Запрещено загружать персональные, закрытые и лицензионно ограниченные данные. На защите студент объясняет все использованные решения без помощи внешнего сервиса.
