# Бенчмарки и baseline

| Задача | Обязательный baseline | Протокол | Метрики | Связанный КИМ |
|---|---|---|---|---|
| Bank Marketing | предсказание наиболее частого класса и простая логистическая регрессия | одинаковое стратифицированное разбиение; `duration` исключён для прогноза до звонка | ROC-AUC как диагностическая, PR-AUC и/или F1 с обоснованным порогом | [КИМ-4](../../M4-modeling/kim-04-modeling.md), [КИМ-5](../../M5-evaluation/kim-05-validation.md) |
| Bike Sharing | среднее по часу/дню недели и линейная модель | временное разбиение без перемешивания; будущие наблюдения не участвуют в обучении | MAE как основная, RMSE как чувствительная к крупным ошибкам | [КИМ-4](../../M4-modeling/kim-04-modeling.md), [КИМ-5](../../M5-evaluation/kim-05-validation.md) |

Числовой порог «достаточно хорошей» модели не фиксируется без привязки к варианту данных. Студент должен превзойти наивный baseline и объяснить практическую значимость улучшения.
