## Правила использования

1. Студент фиксирует выбранный файл, дату получения и контрольную сумму либо версию.
2. В репозиторий проекта не загружаются копии данных, если лицензия или размер этого не требуют; вместо этого приводится инструкция получения.
3. Преподаватель может подготовить варианты выборок, сохраняя источник и лицензию.
4. Собственные данные допускаются только после проверки прав, обезличивания и доступности для рецензента.
