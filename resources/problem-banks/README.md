## Подход к проверке

Единственного эталонного значения метрики нет. Проверяется корректность постановки, отсутствие утечки, воспроизводимость и обоснование решения по соответствующей рубрике. Преподаватель хранит контрольный baseline и диапазон достижимых метрик отдельно от выдаваемых материалов.
