## Подход к проверке

Единственного эталонного значения метрики нет. Проверяется корректность постановки, отсутствие утечки, воспроизводимость и обоснование решения по соответствующей рубрике. Для авторского кейса опубликованы [диагностические диапазоны](../../examples/synthetic-case/teacher/expected_metric_ranges.json), но они не считаются порогами успешности студенческой работы.
