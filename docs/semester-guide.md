# Семестровый план преподавателя

План рассчитан на 16 учебных недель. Точные календарные даты преподаватель подставляет перед началом семестра.

## 2. Ритм работы по модулю

Преподавателю удобно держать один и тот же порядок:

1. выдать КИМ и рубрику до лекции;
2. показать на лекции, какое решение предстоит принять;
3. на лабораторной пройти общий кейс до воспроизводимого результата;
4. дать время перенести решение в студенческий проект;
5. проверить commit и вернуть короткую обратную связь по индикаторам;
6. в начале следующего занятия разобрать две-три типичные ошибки без указания авторов.

## 3. Контрольные точки

| Срок | Что сдаётся | Проверка преподавателя |
|---|---|---|
| 1-я неделя | КИМ-0, без баллов | входные пробелы переведены в адресный план повторения |
| конец 2-й недели | КИМ-1 | постановка согласована до начала работы с моделями |
| конец 5-й недели | КИМ-2 | выводы опираются на данные и не подменяют связь причинностью |
| конец 9-й недели | КИМ-3 | утечка устранена, пайплайн запускается повторно |
| конец 12-й недели | КИМ-4 | baseline и альтернативы сравнимы |
| начало 13-й недели | мини-коллоквиум, без баллов | ошибочная утечка, схема разбиения или метрика исправлены до принятия КИМ-5 |
| конец 14-й недели | КИМ-5 | схема валидации соответствует сценарию применения |
| конец 15-й недели | КИМ-6 | репозиторий и материалы защиты зафиксированы |
| 16-я неделя | защита | студент подтверждает авторство и понимание решений |

## 4. Что подготовить до семестра

- общий учебный кейс для лабораторных;
- два резервных набора данных для проектов;
- диагностический ноутбук для КИМ-0;
- календарь контрольных точек;
- форму для ссылок на commit;
- ведомость баллов по индикаторам;
- расписание защиты на 20 человек;
- один образец хорошего и один образец проблемного аналитического отчёта.

## 5. Что передать на следующий этап

Дисциплина завершает формирование `BD-1` на промежуточном уровне С. Если образовательная программа планирует дальнейшее достижение уровня П, преподаватель передаёт студенту и ответственному за следующий элемент:

- итоговый commit и инструкцию по воспроизведению проекта;
- паспорт данных и перечень известных ограничений;
- рубрики КИМ-2 и КИМ-3 с результатами по `BD-1.2`, `BD-1.3`, `BD-1.5`;
- протокол защиты и вопросы, на которых студенту потребовалась помощь;
- рекомендацию, какие решения нужно перенести на новый домен или более сложные данные.

Следующим элементом может быть углублённая дисциплина, проектный практикум, практика, НИРС или выпускная работа. Курс не делает ни один из этих вариантов обязательным: рабочая группа выбирает продолжение и форму контроля в составе конкретной ОПОП. Возможные артефакты и критерии перехода к уровню П собраны в [траектории роли Data Analyst](role-trajectory.md).
