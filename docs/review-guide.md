# Инструкция внешней команде-рецензенту

## Цель проверки

Проверить согласованность цепочки:

> роль → компетенция → индикатор → предметный дескриптор → КИМ → рубрика → итоговый балл.

## Быстрый сценарий

1. Запустите `python scripts/validate_repository.py`.
2. Прочитайте [РПД](rpd.md) и проверьте достижимость результатов за 108 часов.
3. Выберите по одному КИМ из модулей 1–5 и сопоставьте задание с индикатором.
4. Проверьте, что критерии рубрики наблюдаемы и сумма баллов совпадает с [системой оценивания](assessment-system.md).
5. Проверьте интегральность [проекта](../Project/README.md) и индивидуальность [защиты](../Exam/README.md).
6. Зафиксируйте замечания в Issue либо Pull Request с указанием файла и критерия.

## Вопросы рецензенту

- Можно ли по формулировке КИМ однозначно понять, что сдаёт студент?
- Позволяет ли рубрика различить базовое выполнение и самостоятельный обоснованный выбор?
- Есть ли результат обучения, который не подтверждается артефактом?
- Не оценивается ли один и тот же результат дважды без добавления нового уровня сложности?
- Достаточны ли данные и ресурсы для выполнения задания?
- Прозрачны ли правила применения генеративного ИИ?
- Можно ли воспроизвести итоговый проект из чистого окружения?
