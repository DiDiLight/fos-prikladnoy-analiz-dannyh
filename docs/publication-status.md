# Статус учебно-методического комплекта

## Учебный контекст

| Поле | Значение |
|---|---|
| Дисциплина | «Прикладной анализ данных» |
| Направление | 01.03.02 «Прикладная математика и информатика» |
| Семестр | 6-й |
| Объём | 3 ЗЕТ, 108 часов |
| Аттестация | дифференцированный зачёт с индивидуальной защитой |
| Роль КРМ | Data Analyst |
| Целевые компетенции | `LC-1`, `BD-1`, `ML-2` |

Комплект создан как результат учебной работы по разработке РПД. Он пригоден для методического рецензирования и пробного проведения, но не является утверждённой РПД конкретной образовательной организации.

## Авторство

Владельцем и координатором репозитория указан профиль [`DiDiLight`](https://github.com/DiDiLight). Официальные ФИО, должность и организация не выводятся из имени учётной записи: такие данные можно публиковать только после подтверждения автором. Текущая зона ответственности приведена в [карточке команды](../team/README.md).

## Что уже определено

- название, цель и трудоёмкость дисциплины;
- учебный контекст: направление 01.03.02, 6-й семестр;
- три целевые компетенции и их индикаторы;
- промежуточный уровень С по `BD-1`;
- 100-балльная модель и шкала `50–69 / 70–85 / 86–100`;
- КИМ, рубрики, регламент защиты и воспроизводимый учебный кейс.

## Что требует решения организации

- включение дисциплины в конкретную ОПОП и учебный план;
- официальные сведения об авторах и ответственном подразделении;
- локальная форма утверждения РПД и ФОС;
- выбор элемента программы, в котором подтверждается уровень П по `BD-1`;
- окончательное решение о лицензиях перед официальной публикацией.

Возможные последующие дисциплины, практика, НИРС и выпускная работа описаны как варианты продолжения. Этот комплект не устанавливает их обязательность.
