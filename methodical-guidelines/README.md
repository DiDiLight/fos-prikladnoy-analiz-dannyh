# Методические указания

| Раздел | Для кого | Содержание |
|---|---|---|
| [students](students/README.md) | обучающиеся | выполнение, сдача, воспроизводимость и защита КИМ |
| [teachers-assessment](teachers-assessment/README.md) | преподаватели | проверка работ, фиксация индикаторов, защита и апелляции |

Основной принцип прост: преподаватель оценивает конкретный результат и объяснение студента, а не количество кода, библиотек или сложность выбранной модели.
