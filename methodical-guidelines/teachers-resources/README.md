# Методические указания преподавателям по использованию ресурсов

## 1. Выбор кейса

Кейс должен содержать пользователя результата, решение, ограничение и доступные данные. Избегайте постановок «построить модель с максимальной точностью» без прикладного контекста.

## 2. Выбор данных

Проверьте источник, лицензию, объём, состав признаков, целевую переменную, смещения и возможные утечки. До семестра сохраните контрольную сумму либо версию набора. Не используйте реальные персональные данные без правового основания и обезличивания.

## 3. Учебная сложность

Данные должны содержать содержательные решения, но оставаться выполнимыми за 3 ЗЕТ. Рекомендуется один основной набор на команду и управляемый мини-кейс для первого прохода CRISP-DM.

## 4. Программное окружение

- Зафиксируйте поддерживаемую версию Python и диапазоны библиотек.
- Проверьте установку на чистой машине.
- Подготовьте минимальный тестовый ноутбук.
- Не меняйте обязательную версию окружения после начала оцениваемой работы без миграционной инструкции.

## 5. Внешние материалы

Для каждого ресурса укажите назначение, связанные КИМ, доступ, лицензию и дату проверки. Не размещайте защищённые файлы в репозитории без разрешения; используйте библиографическую и устойчивую внешнюю ссылку.

## 6. Обновление

Перед каждым запуском курса проверяйте ссылки, версии библиотек, доступность данных и соответствие КРМ. Изменение КИМ сопровождайте новой версией или отдельным коммитом, чтобы сохранялась воспроизводимость прошлых оценок.
