# Шаблон ведомости по индикаторам

В рабочей таблице преподавателя одна строка соответствует одному студенту.

| Студент | `LC-1.1` /14 | `BD-1.2` /18 | `BD-1.3` /9 | `BD-1.5` /8 | `ML-2.1` /15 | `ML-2.2` /15 | `ML-2.3` /21 | Итого /100 | Защита пройдена | Оценка |
|---|---:|---:|---:|---:|---:|---:|---:|---:|:---:|:---:|
|  |  |  |  |  |  |  |  |  |  |  |

Минимальные пороги: 7, 9, 5, 4, 8, 8 и 11 баллов соответственно.

Дополнительно удобно вести лист контрольных точек:

| Студент | КИМ-1 /10 | КИМ-2 /15 | КИМ-3 /15 | КИМ-4 /20 | КИМ-5 /15 | КИМ-6 /15 | Защита /10 | Ссылка на итоговый commit |
|---|---:|---:|---:|---:|---:|---:|---:|---|
|  |  |  |  |  |  |  |  |  |

Сумма по КИМ должна совпадать с суммой по индикаторам. Если не совпадает, ошибка находится в переносе баллов, а не исправляется ручной корректировкой итога.
